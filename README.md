# Smart Planner

## 소개

Smart Planner는 일정 관리, 할 일(To-Do), 목표 추적 기능을 통합하여 사용자의 생산성을 높여주는 플래너 애플리케이션입니다.

하루 일정을 체계적으로 관리하고, 중요한 목표를 지속적으로 추적할 수 있도록 설계되었습니다.

## 주요 기능

### 📅 일정 관리

* 일별, 주별, 월별 일정 조회
* 일정 추가, 수정, 삭제
* 반복 일정 설정

### ✅ 할 일 관리

* To-Do 리스트 생성 및 관리
* 우선순위 설정
* 완료 상태 추적

### 🎯 목표 관리

* 단기·장기 목표 설정
* 목표별 진행률 확인
* 마일스톤 관리

### 🔔 알림 기능

* 일정 및 할 일 알림
* 중요 일정 리마인더 제공

### 📊 생산성 분석

* 완료한 업무 통계 제공
* 목표 달성 현황 시각화
* 주간·월간 활동 리포트

## 기술 스택

* Frontend: React / Next.js
* Backend: Node.js / Express
* Database: PostgreSQL
* Authentication: JWT

## 사용 방법

### 설치

```bash
git clone https://github.com/your-repository/smart-planner.git
cd smart-planner
npm install
```

### 실행

```bash
npm run dev
```

브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:3000
```
